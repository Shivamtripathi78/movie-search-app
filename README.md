# CineScope — Movie Search App

A responsive movie discovery application built with HTML, CSS, and JavaScript using the TMDB API.

## Features

* Search movies by title
* Browse popular movies
* View movie posters, ratings, release years, and summaries
* Explore additional movie details
* Load more search results
* Responsive design for desktop and mobile
* Loading indicators and error handling

## Tech Stack

* HTML5
* CSS3
* JavaScript
* TMDB API

## Setup

1. Clone the repository.
2. Create a local `config.js` file.
3. Add your TMDB read-access token to `config.js`.
4. Open `index.html` using VS Code Live Server.

Keep `config.js` out of version control. Browser-based credentials are not truly secret; use a protected backend for public deployments.

## API

Movie information is provided by [The Movie Database (TMDB)](https://www.themoviedb.org/).

This product uses the TMDB API but is not endorsed or certified by TMDB.

## Purpose

Created as part of a 30-day coding challenge to practice frontend development, asynchronous JavaScript, API integration, and responsive UI design.
